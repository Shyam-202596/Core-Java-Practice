# Java Generics Assignments

## 1. Store Any Data Type Using a Generic Class

Write a program to create a class named `MyClass` that can store an object of any data type.

---

## 2. Display Array Elements Using a Generic Method

Write a generic method that receives an array and displays its elements. The array elements may be of any data type.

---

## 3. Generic Interface and Implementation Class

Write a program to create a generic interface named `Fruit` and a generic implementation class named `AnyFruit`. Use the implementation class to determine the taste of fruits such as a banana and an orange.

---

## 4. Generic Hashtable

Write a program to create a `Hashtable` using generic types so that it can store different types of data.
