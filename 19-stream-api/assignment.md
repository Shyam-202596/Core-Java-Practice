# Java Stream API Assignments

## 1. Filter ArrayList Elements

Write a program to create a stream with the elements of an `ArrayList` and collect the elements greater than 5 into a new list.

---

## 2. Convert Stream into an Array

Write a program to retrieve numbers from an `ArrayList` and convert the resultant stream into an array.

---

## 3. Create Streams Using Stream.of()

Write a program to understand how to create streams of objects using the `Stream.of()` method.

---

## 4. Generate Random Numbers Using Stream.generate()

Write a program to generate random numbers using the `Stream.generate()` method.

---

## 5. Perform Stream Operations

Write a program to understand how to perform some important operations on streams using the methods of the `Stream` class.
