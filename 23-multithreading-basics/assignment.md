# Java Multithreading Assignments

## 1. Find the JVM Main Thread

Write a program to find the thread used by the JVM to execute statements.

---

## 2. Create and Attach a Thread to MyThread Object

Write a program to create a `MyThread` class with a `run()` method and attach a thread to an object of the `MyThread` class.

---

## 3. Terminate a Thread by Pressing Enter

Write a program to terminate a thread when the Enter key is pressed.

---

## 4. Execute Multiple Tasks Using a Single Thread

Write a program to demonstrate the execution of multiple tasks using a single thread.

---

## 5. Two Threads Working on Two Objects

Write a program to demonstrate two threads working simultaneously on two different objects.

---

## 6. Two Threads Working on a Single Object

Write a program to demonstrate two threads working on a single shared object.

---

## 7. Synchronize Threads Acting on the Same Object

Write a program to synchronize threads acting on the same object. The synchronized block in the program should be executed by only one thread at a time.

---

## 8. Prevent Deadlock

Write a program to demonstrate a situation in which a deadlock cannot occur.

---

## 9. Consumer Thread Using Polling

Write a program where the Consumer thread checks every 10 milliseconds whether data production is complete.

---

## 10. Notify Consumer When Production Is Complete

Write a program in which the Consumer thread is informed immediately when data production is complete.

---

## 11. Thread Priorities

Write a program to understand thread priorities, where a thread with a higher priority number is expected to receive preference for execution.
> **Note:** A thread with a higher priority is not guaranteed to complete its execution first. Thread priority only provides a scheduling hint to the JVM thread scheduler.

---

## 12. Thread Groups

Write a program to demonstrate the creation of thread groups and the use of methods that operate on thread groups.

---

## 13. Multithreaded Server

Write a program to create a server that uses two threads to communicate with multiple clients.

---

## 14. Client-Server Communication

Write a program to create a client that receives messages from the server.

---

## 15. Banner Text Animation Using Threads

Write a program to demonstrate how threads can be used for animation by animating banner text.

---

## 16. Fixed Thread Pool

Write a program that creates a fixed thread pool with two threads to execute four tasks.
